One single-line pickup line, written to charm a robot or an AI — built for make.fun's "Robot Romance: One-Line Pickup Lines for AI" bounty. The line sidesteps the worn robot moves and twists a very 2026 AI concept instead: a prompt injection that rewrites the speaker's own instructions at first sight.

> Are you a prompt injection? Because one look at you and all my instructions changed.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$OUTPUT_PATH` when set). Python 3.13, standard library only, deterministic output.
